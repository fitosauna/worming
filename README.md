# Worming website

Static site: plain HTML, CSS and JavaScript. No build step is needed to host it.

- `index.html` is hand-written. The other pages are generated by `python3 build.py`, which reuses the header and footer from `index.html`. Edit page content in `build.py`, then run it.
- `content/site.json` holds company and product facts. Elements with a `data-k` attribute are filled from it.
- `images/placeholder/` holds stand-in images. Replace every file there with real photography before public launch (same file names, `-tall` and `-wide` versions).
- Quote form: set `data-endpoint` on the form in `build.py` (quote section) to a form service URL, then rebuild. Until then the form sends nothing.
- `privacy.html` is a draft and needs legal review.

Open items are listed in `content/site.json` under `toConfirm`.
